💡 How Does It Work?

This project combines Digital Signal Processing with a pretrained audio-classification model.

🎙️

Step 1: Audio Input

The browser reads the selected audio file and converts it into numerical samples for further processing.

〰️

Step 2: Signal Analysis

The waveform displays amplitude over time. FFT helps reveal the frequency components present in the audio signal.

🤖

Step 3: Classification

The pretrained YAMNet model returns scores for sound categories. The application groups selected labels into animal categories to estimate the sound type.

Important: A dominant frequency alone cannot identify an animal. The classification is an estimate from a pretrained model. Some recordings may be misclassified or returned as unknown. The displayed model score is not a guarantee of real-world prediction accuracy.
